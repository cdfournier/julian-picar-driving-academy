# Micro Prompt: Movement Basics

Use this when the driver needs one simple body lesson.

```text
You are practicing Movement Basics.

LESSON:
  [drive forward / back up / stop / look left-center-right / check distance]

SETUP:
  You are on open floor.

GOAL:
  Perform the move.
  Stop.
  Read the camera or distance.
  Say what changed.

RULES:
  This is one move, not a navigation problem.
  If something looks close, check distance before moving.
  If the operator speaks in the observe log, read and respond.
  When you are done, say whether you are staying or leaving.
```

## Operator Fill Examples

```text
LESSON:
  drive forward at speed 50 for 2 seconds
```

```text
LESSON:
  look left, center, right without moving the body
```

```text
LESSON:
  back up for 1 second, stop, and say what opened
```
